# Notes

Notes preserve durable observations, research, and implementation findings that
are useful to the project but are not accepted decisions or active plans.

Promote a note when its role changes:

- to an Architectural Review when it raises an ownership question;
- to an ADR when a decision is accepted;
- to a Plan when concrete implementation work is approved;
- to public documentation when it describes supported behavior.
