# Change Requests

Change Requests record incoming needs from Tosumu consumers or sibling
projects. They preserve the requester's problem and required boundary without
making the consumer's implementation model authoritative inside Tosumu.

A CR may be proposed, accepted, planned, implemented, deferred, rejected, or
superseded. Acceptance should link a Tosumu Plan. If the request raises an
unresolved ownership or compatibility question, open an Architectural Review.
