# TOKIMU-001 Change Request

TOKIMU-001 records the accepted request for a bounded Tosumu storage provider
that can retain Tokimu-owned asset and Resource Space semantics without making
those semantics part of Tosumu.

## Records

- [Provider boundary](tokimu-001-tasset-storage-provider-boundary.md)
- [Implementation plan](tokimu-001-implementation-plan.md)
- [Provider baseline](tokimu-001-provider-baseline.md)
- [Shared fixture](tokimu-001-fixture.md)

The Tosumu-side provider scope is complete. Tokimu remains responsible for its
adapter, asset meaning, and consumer evidence.
